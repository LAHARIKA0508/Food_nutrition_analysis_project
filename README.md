# Food & Nutrition SQL Analysis

## Project Overview

This project analyzes food, nutrient, dietary requirement, and food consumption data using PostgreSQL and SQL.

The goal is to explore nutritional information and food consumption patterns using a relational database.

## Database Structure

The database contains five tables:

- `foods`
- `nutrients`
- `food_nutrients`
- `dietary_requirements`
- `food_consumption`

## SQL Concepts Used

- SELECT and filtering
- INNER JOIN
- LEFT JOIN
- GROUP BY
- Aggregate functions
- Subqueries
- CASE statements
- Date functions
- Window functions
- RANK()
- Nested queries

## Tools

- PostgreSQL
- pgAdmin
- SQL
- GitHub

## Analysis Questions

The project answers 10 SQL analysis questions covering food nutrition and consumption.

1. Protein content by food
2. Foods with high calcium content
3. Average protein by food category
4. Food count by category
5. Foods above average protein
6. Foods never consumed
7. Protein ranking within food categories
8. High- vs low-protein food classification
9. Monthly food consumption
10. Top 2 calcium-rich foods by category
